ماوون، روی دستگاه شما

نسخه ۰.۷.۲ • وب‌اپ قابل نصب برای آیفون، مک و ویندوز

باز کردن نرم‌افزار

این نسخه بدون اطلاعات آزمایشی شروع می‌شود. اولین ورود، حساب مدیر با نام کاربری و رمز انتخابی شما ساخته می‌شود. اطلاعات محلی هر دستگاه جداست؛ برای اشتراک اطلاعات، دکمه همگام‌سازی داخل برنامه را روی هر دستگاه فعال کنید. ابتدا حساب مدیر را بسازید و سپس حساب‌های پرسنل را تعریف کنید. برای اتصال دستگاه‌ها، همگام‌سازی را فعال کنید. اگر پس از نصب اطلاعات قبلی دیده نشد، پشتیبان را بازیابی کنید.

آیفون

  1. لینک نرم‌افزار را در Safari باز کنید و در صورت نیاز وارد حساب ChatGPT خود شوید.
  2. دکمه اشتراک‌گذاری (Share) را بزنید.
  3. «افزودن به صفحه اصلی» (Add to Home Screen) و سپس Add را انتخاب کنید. اگر گزینه Open as Web App نمایش داده شد، فعالش کنید.

آیکون ماوون روی صفحه اصلی ظاهر می‌شود. برای این روش فایل IPA لازم نیست.

مک

برای نسخه مستقل مک M1/M2/M3/M4، بسته «Mavon-Mac-AppleSilicon-0.7.2.zip» تحویل‌شده در گفت‌وگو را باز کنید. نصب‌کننده Install-Mavon.command برنامه را در پوشه Applications حساب شما می‌گذارد. بسته امضای رسمی اپل ندارد و اجرای آن روی مک در این محیط آزمایش نشده است. اطلاعات مرورگر خودکار به برنامه منتقل نمی‌شود؛ ابتدا از طریق سرور همگام کنید یا پشتیبان JSON بگیرید.

لینک برنامه را در Chrome باز کنید. از منوی مرورگر، گزینه نصب برنامه یا Install page as app را انتخاب کنید؛ این گزینه ممکن است زیر Cast, save and share باشد. اگر دکمه نصب بالای این صفحه ظاهر شد، از همان استفاده کنید.

در Safari، اگر موجود بود، از File → Add to Dock استفاده کنید.

ویندوز

در Microsoft Edge، لینک برنامه را باز کنید و از منوی Apps → Install this site as an app نصب کنید. در Chrome از گزینه نصب برنامه در منو یا نوار آدرس استفاده کنید.

دانلود میان‌بر ویندوز

درباره این نسخه

فایل‌های میان‌بر بالا نصب‌کننده نیستند. نسخه مستقل مک برای Apple Silicon به‌صورت بسته .app جداگانه تحویل داده می‌شود؛ نسخه مستقل ویندوز و آیفون در این بسته نیستند. نصب از طریق قابلیت وب‌اپ مرورگر انجام می‌شود و نمایش گزینه نصب به مرورگر و تنظیمات دستگاه بستگی دارد.

برای بارگذاری اولیه به اینترنت نیاز است. پس از ذخیره شدن فایل‌ها، بخش‌های محلی می‌توانند آفلاین کار کنند؛ ورود به حساب و بازشدن مجدد سایت خصوصی ممکن است اینترنت بخواهد. آفلاین بودن در همه دستگاه‌ها تضمین نشده است.

پاک‌کردن داده‌های مرورگر یا برنامه ممکن است اطلاعات محلی را حذف کند. پشتیبان JSON قابل بازیابی است؛ خروجی اکسل جایگزین آن نیست.

این نسخه تازه به سرور متصل شده است. پیش از انتقال کامل کارتان، روند فروش، دریافت و بازیابی پشتیبان را با اطلاعات آزمایشی بررسی کنید.
